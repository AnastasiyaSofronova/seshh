# Василий Юшков — Фотосайт

Стильный минималистичный сайт-портфолио.

## Как выложить на GitHub Pages

1. Создай новый **Public** репозиторий на GitHub
2. Загрузи все файлы из этой папки (через Upload files)
3. Зайди в **Settings → Pages**
4. Source: ветка `main`, папка `/ (root)`
5. Сохрани. Через минуту сайт будет доступен.

Адрес будет примерно таким:  
`https://твой-ник.github.io/название-репозитория/`
